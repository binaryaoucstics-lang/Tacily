# 默译 · Tacily 品牌素材

- `tacily.svg`：标准 Logo，使用最新接缝对齐版 v4 的标准饱和度蓝绿配色。蓝色尖端、内边缘与圆弧共用同一接点。
- `tacily-icon256.png`：透明图标，用于应用与扩展；由 SVG 等比例渲染并保留安全边距。
- Windows ICO 位于 `src/ScreenTranslator.App/Assets/ScreenTranslator.ico`。
- 浏览器图标位于 `browser-extension/icons/`。

SVG 为可编辑纯矢量。品牌素材按仓库根目录的 PolyForm Noncommercial License 1.0.0 提供，详见 [许可说明](../../docs/LICENSING.md)。
