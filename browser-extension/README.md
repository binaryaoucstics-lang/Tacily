# Chrome 网页与图片翻译扩展 0.6.0

配套全局 AI 翻译器桌面版 0.10.0。按桌面程序“常规”页的引导加载扩展、连接桌面组件；升级时重新加载扩展并刷新网页。

- 自动判断网页语言并分段流式翻译公开正文、导航、标题和按钮；可手动翻译选中文本或整页。
- 默认并发 10。原文／译文／双语切换在已有译文后显示；图片不做双语。全屏视频隐藏悬浮条。
- 识别与分块采用固定 4 ms 时间片，让出浏览器主线程；共享样式与几何数据，未变段落复用源文 SHA-256。
- 滚动、布局变化和展开内容触发补充识别，独立动态加载不再取消现有流式任务。
- 新页面语言判断与旧页面翻译并行；临时连接失败有限重试，无法判断时明确结束准备状态。
- 格式错误由桌面端对受影响小组重试；成功译文在页面重建、刷新和返回时利用缓存重放。
- 图片通过页内覆盖层跟随滚动，局部更新保留已显示切片。动效开关位于桌面常规设置。

扩展不存储 API Key，只与本机桌面桥通信。输入框、表单、编辑器、隐藏内容和代码不进入自动文本翻译；整图翻译按桌面端设置发送至配置的模型服务。

测试：`node --test (Get-ChildItem ./browser-extension/tests -Filter *.test.js).FullName`。测试集使用合成内容和本地传输替身，不读取个人浏览器资料。
