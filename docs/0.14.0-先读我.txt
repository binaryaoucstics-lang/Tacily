全局 AI 翻译器 0.14.0 / Chrome 扩展 0.9.0

升级：退出旧程序，将本包解压到新目录，运行 ScreenTranslator.exe。
在 Chrome 扩展管理页重新加载本包 browser-extension 目录中的扩展至 0.9.0，再刷新已有网页。
API Key、服务商预设、已验证译文缓存及原有设置沿用。

新增：
1. 网页悬浮窗圆点可折叠、展开及按住拖动，位置自动限制在视口内。
   翻译中蓝色转圈，准备中紫色呼吸，完成绿色，部分保留原文黄色，失败红色，空闲灰色。
   图片翻译状态也会反映在圆点上；折叠不打断翻译。全屏看视频时仍隐藏。
2. 展开后的悬浮窗点击小箭头，可再次展开快捷设置：自动网页翻译、自动图片策略、目标语言、并发数及当前网站规则。
   保存后同步至桌面设置及其他标签页。动效设置仍在桌面程序中。
3. 常规设置新增网站白名单和黑名单，支持多行域名或网址。悬浮窗可快捷设置当前网站。
   规则包含子域名；更具体的域名优先，同域名冲突时黑名单优先。
   白名单在自动网页翻译开启时跳过整页语言判断，仍过滤不需要翻译的段落。
   黑名单停止自动文字和图片翻译，保留手动翻译入口和已有译文。
   “遵循默认”移除当前域名的单独规则；父域名规则仍可能生效，菜单会说明。

保留：默认并发 10、译文缓存 256 MB。图片默认不自动翻译，可选择仅大图 / 点开放大后判断。
“翻译选中”点击段落即可选择，无需手动高亮；Esc 可退出选择。
本次未增加依赖、模型权重或浏览器权限。

测试与限制：1705 项自动化测试通过，圆点及快捷菜单真实网页交互使用受控响应验证；新版发布程序完成离线运行检查。
本轮没有使用用户 API Key 调用翻译服务。详细证据见 docs/0.14.0-验证报告.md。
