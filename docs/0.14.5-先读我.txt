全局 AI 翻译器 0.14.5 / Chrome 扩展 0.9.3

新增 Clash 节点延迟测试、可用性检测和延迟排序，以及真实 API 翻译测速。

翻译设置 → API 网络连接 → Clash 指定节点：
1. 读取 Clash 节点。
2. 测选中节点或测速全部；可随时停止。
3. 按延迟排序，可用节点优先。排序不更换已选节点，也不切换 Clash 主内核的手动选择。
4. 为不同 API 预设选择节点并保存。

节点测速通过本机 Clash 控制接口发起通用 HTTPS 检测，并确认测试 URL 的响应状态；批量并发 8，单节点超时 5 秒。不为每个待测节点创建独立内核。节点可连接不代表当前 API 一定有权限，请再做翻译测速。

点击“翻译测速”会用当前预设的协议、模型、线路和思考配置，把固定英文句子真实翻译为简体中文。显示流式译文、首字延迟、总耗时及 TPS，并支持取消。
首字指第一个非空译文字出现，包含连接准备、等待和思考。
TPS 来自服务商返回的实际 token 用量，不用字符数估算。思考用量已知时从内容生成速率中排除；无分项时明确显示含等待与思考的整体输出 TPS；没有 token 用量或流式时间样本不足时显示“—”。输出格式 token 计入输出量。
测试不读取网页、剪贴板或图片，不使用翻译缓存或格式修复重试。

同时修复 X 日语活动贴文中的日期校验误判：11/8(日)、11/8（周日）、11月8日（周日）按等价日期识别。错误的日期、星期和金额仍会被拒绝。

升级：退出旧程序，解压新包到新目录运行。保留设置及 API Key。Chrome 扩展本版无需更新。
