0.11.0 服务商预设验证

1. 启动新版，确认已有服务商与密钥仍可使用。
2. 翻译设置点击新增，设置名称、协议、模型、地址、API Key，保存并测试连接。
3. 再新增另一个服务商预设，使用不同地址/模型/密钥。
4. 反复切换，确认参数和密钥掩码对应当前预设；测试连接结果不能串到另一预设。
5. 复制当前配置，确认复制后可独立修改；原配置保持可用。
6. 重启软件，确认预设与选中状态恢复。
7. 使用当前预设翻译网页文字与图片，确认文字流式输出与原位嵌字正常。

自动测试使用合成响应与临时 DPAPI 密钥，不使用个人 API Key。
第三方服务实际模型权限、视觉输入和协议实现请用连接测试确认。
