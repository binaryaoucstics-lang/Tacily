# 0.14.5 验证报告

桌面 0.14.5，Chrome 扩展保持 0.9.3。

## 节点检测与翻译测速

- 节点支持单个或批量测速、取消、延迟排序和状态标记。排序保留预设当前选择，可用节点优先，不可用节点置后。
- 使用主内核 URL 测试接口，固定并发 8、单节点 5 秒超时；确认对应 URL 的 HTTP 可用状态，防止把错误站点响应的非零延迟标成可用。旧内核不提供状态时标为“可连接”。
- API 连接测试替换为一次实际的固定句子流式翻译，使用所选协议、模型、线路与思考配置；取消或切换配置会隔离旧结果。
- 首字延迟记录首个译文字；内容 TPS 使用真实 token 用量，扣除已知推理 token，以首个至最后内容数据的客户端持续时间计算。JSON 等结果格式 token 也计入输出。分项未知时明确显示整体输出 TPS，含网络等待和思考。没有用量或样本不足时不估算。
- 显示真实译文、首字、TPS、总耗时和统计口径。不使用翻译缓存、自动格式修复或字符数估算测速。

## 实际测试

通过已安装 Clash 直接检测 16 个节点，15 个通过、1 个不可用；批量约 1.44 秒完成，可用延迟为 17–372 ms。本次结果仅代表测试时的连接情况。

使用正常用户环境中已配置的 API 预设进行真实翻译，成功返回固定测试句的中文译文：首字约 875 ms、总耗时约 1.01 秒、44 个输出 token、约 195.6 TPS。短句结果受网络、服务商负载和数据包合并影响，不是模型稳定吞吐量承诺。未公开密钥、节点名称或自定义接口地址。

## X 日期校验修复

在当前真实 Chrome 中复现用户提供的日语活动贴文：流式译文出现后，最终数值/日期校验拒绝整组，恢复原文。原文的日语缩写 `11/8(日)` 与实际译文 `11/8（周日）` 未被识别为等价日期。

补充与日期相邻的日语星期缩写，以及相应中文写法；没有放宽错误日期、星期或数值保护。修复后的真实页面保持中文译文；上下滚动后正文相同、没有回到日语原文。新增 Core 与流式提交/缓存重放回归覆盖。
