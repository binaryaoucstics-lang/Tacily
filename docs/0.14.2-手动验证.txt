0.14.2 验收操作

升级桌面程序和 Chrome 扩展后刷新网页。
1. 点击网页悬浮窗的“翻译选中”，点击图片，确认读到整张原图并出现原位译文；点击普通段落仍应翻译该段，不需要先高亮选中。
2. 关闭自动图片翻译时，手动点击图片仍可翻译。点击图片链接不能意外跳转；Esc 关闭当前图片译文。
3. 在设置中开启“大图/点开放大”自动图片模式。X 信息流中的小缩略图应保持原样，打开图片查看器后，大图才进入本地文字判断。有外语文字才发送到翻译服务。
4. X 日语贴文完成后，滚动、加载新贴文、展开内容和切换原文/译文；未改变的原文应复用缓存。贴文实际改字后应翻译新内容。
5. 中文夹英文段落不应送翻译；同一贴文分行包含中文和日语时中文行保持原样。日语中的汉字加假名仍正常翻译。
6. 原有服务商预设、读取模型列表、圆点折叠/拖动、快捷设置、网站黑白名单应继续可用。

本轮已执行自动回归、原图读取/嵌字链路及独立 Chrome DOM 操作测试。真实 X 贴文访问在测试环境返回 403；真实账号的接口响应和页面版本仍需实际环境验收。
