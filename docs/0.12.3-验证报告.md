# 0.12.3 日期语境与短句语序

## 原因与修改

模型列表将 Updated 和时间分别放在文本节点与 TIME 元素中。旧版本对日期节点直接进行本地替换，另一节点单独翻译，最终拼接仍保持英文语序。

- 本地转换依据完整语义组，单个文本节点像日期不足以认定它是独立标签。
- 只读短句或普通段落的时间及相邻文本合并成一个模型输入，允许中文自然调整语序。结果投影到原有文本节点，不删除 TIME 元素或修改 datetime。
- 保留原文、完成译文、流式输出、重绘及缓存绑定。合并不跨越链接、按钮、输入或代码；这些区域的日期片段也不会直接本地替换。
- 正式后台同样检查完整源范围及来源上下文，防止将句中日期误当成独立日期。

## 真实页面

独立匿名 Chrome for Testing，加载正式前端模块，以本地控制的流式响应验证输入及渲染；不调用用户云 API。

| 页面 | 检查结果 |
|---|---|
| Qwen-Image-2.1-Turbo 量化模型列表 | 24 条 Updated 短句完整送入翻译；未单独发送裸日期；均按“约…前更新”显示 |
| 模型列表重绘和复制已译节点 | 恢复完整译文，复制后新增请求为 0 |
| 模型列表原文/译文切换 | 恢复完整英文短句和完整中文译文 |
| TIME 结构 | datetime 属性保留 |
| Spaces p=3 | 24 个独立日期仍在本地转换，日期 API 请求为 0 |

时间值随站点更新；测试只固定语序与输入边界。流式测试不作为云模型翻译质量评测。

新增覆盖整条 Updated 短句的模型请求和缓存重放、日期源范围与上下文判断、段落日期输入、流式语序、更新时间后的完整请求、原文切换及重绘恢复。
