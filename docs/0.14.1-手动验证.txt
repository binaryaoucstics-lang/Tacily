0.14.1 验收操作

升级后在翻译设置中选择自定义服务商预设，填写协议、Base URL 和 API Key。
点击“读取模型列表”，确认自动展开。选择模型后保存，切换预设及重启后所选模型应保留。
读取时可取消，或切换到其他服务商；旧服务商返回的结果不应覆盖新服务商。
列表接口不支持时，仍能手动填写模型 ID 并保存。
本机 OpenAI 兼容服务（例如 http://localhost:1234/v1）可不填 API Key。
用于图片翻译的模型须支持图像输入；模型列表不保证所有模型都能用于当前翻译方式。

Chrome 验证：opengateway.ai 的主标题及简介翻译完成后应固定；倒计时、轮播、滚动和原文切换不应重启已完成的正文翻译。
原有圆点折叠拖动、快捷菜单、网站黑白名单仍可使用。

本轮已运行自动化、受控 HTTP 和实际 WPF 控件验证；真实账号服务商的接口响应取决于其提供的模型列表及账号权限。
