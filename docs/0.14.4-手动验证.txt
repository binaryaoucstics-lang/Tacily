全局 AI 翻译器 0.14.4

本版已完成自动化、实际 Clash 网络与 WPF 控件验证。可按需检查：

1. 翻译设置中为两个 API 预设分别选择直连和 Clash 指定节点，保存并来回切换，确认选择独立恢复。
2. 启动 Clash Verge，读取节点列表，为两个预设选不同节点，测试连接、读取模型列表和翻译。
3. 确认 Clash 自身当前节点没有随预设切换变化；已有网页译文缓存仍然有效。
4. 无 Clash 的电脑选择 Clash 功能时，应出现官方 GitHub 下载入口；直连和自定义代理仍可用。
5. 退出翻译软件后，其独立节点通道应退出，Clash Verge 原进程继续运行。

直连不覆盖系统 TUN / VPN。自定义代理使用不带账号密码的 HTTP / HTTPS / SOCKS5 URL。
