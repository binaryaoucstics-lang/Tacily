# 0.10.0 验证报告

桌面版本 0.10.0，Chrome 扩展版本 0.6.0。

## 修复与验证

| 问题 | 修改 | 验证 |
|---|---|---|
| 自动翻译漏段，手动整页才能补上 | 滚动／布局变化补充发现；新增独立段落延后扫描，不取消现有任务；格式错误对小组有限重试 | 真实 Qwen 页与回归用例通过 |
| 新页一直“正在准备翻译” | 最多 4 个页面任务并行；所有页面共享最多 10 个模型请求；判断前拒绝请求明确结束等待，临时错误最多重试 2 次 | 旧页未完成时新页能返回判断；永久失败不再无限等待 |
| 模型格式错误影响其他段落 | 每组最多 4 个块重试；重试预算预留，成功段落独立保留 | 畸形 JSON、截断 SSE、并发、取消、事实保护与缓存测试通过 |
| 发布体积与私有内容 | 移除旧大模型、Python 链路、额外 VLM 定位、不使用的视频编解码与识读资源；剔除个人截图和旧测试记录 | 资源、隐私导出、独立源码构建通过 |

## 测试结果

- .NET 核心测试：702 通过；集成测试：596 通过；Node 扩展测试：268 通过，均无跳过。
- 独立复制的公开源码在 Windows 上恢复依赖、构建成功，0 警告、0 错误；核心和集成测试均通过。测试不依赖原开发目录寻找模型。
- 两张生图漫画的颜色、擦字、横／竖排嵌字回放保留；用户提交的漫画、个人截图、旧 OCR 输出和接口日志不包含在公开源码。
- 实际发布程序运行检查通过：本地图片判断、NTextCat 模型、字库、三处原位嵌字、API 设置、缓存控件、动效控件与默认并发 10。检查未读取密钥、联网或采集桌面。
- 独立 Chrome 工具栏和动效检查：32 项通过。测试浏览器已关闭，使用临时资料，不操作个人 Chrome。

## 资源与公开源码

本地模型资源约 22.9 MiB，保留 7 个字体文件；无 CRAFT、Comic Text Detector、Python／OCR 大模型、日语校正词典或 FFmpeg。模型判断与字形处理均使用 CPU。

字体和中文识读权重通过固定版本、SHA-256 清单获取；8 项资源在独立空目录下载与校验全部通过。公开源码排除这些大二进制，包含获取脚本、许可、说明、生成素材与回归测试。

导出使用明确的文件范围，排除工作记录、浏览器资料、用户配置、密钥、缓存、日志、个人截图、编译产物和旧实验；敏感内容扫描无发现。扩展 manifest 的 key 是固定扩展身份用的公开公钥。

程序包与源码包的 SHA-256、大小见随包校验文件和发布目录。GitHub 推送、发行发布及签名由后续发布流程处理。
