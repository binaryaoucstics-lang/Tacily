## 修复与验证范围

手动选图：网页入口从段落拾取改为图片优先、段落回退。图片拾取只发送注册 ID，后台核对当前标签、文档、图片身份和配置代数后才读取整张原图。复用原有原位嵌字与图片缓存。手动选图不受自动图片开关和自动网站黑名单限制，也不会取消并行的正文批次。测试覆盖身份隔离、导航、重复请求、断线、迟到状态、显式手动模式绕过本地自动否定及缓存重放。

X 图片查看器：在已开启自动图片模式时，查看器内的大图独立进入本地判断，保留尺寸、可见性、域名规则及配置约束。整页中英混合判定不再挡住该图片；缩略图仍不自动读取。其他网站整页混合判定行为不变。

X 文字：合并 tweetText 内 span/div 的段落语境；中文夹英文段落及分行的中文部分在构建请求、上下文、判断样本前过滤。假名作为日语证据，避免将日语汉字当成中文整页跳过。未改变原文的节点移动、框架重绘和纯文本 span 边界改变重放已完成译文，真实字句变化重新翻译。缓存不覆盖链接等独立交互结构。

## 浏览器操作检查

独立 Chrome for Testing，1440×1000，实际注入生产内容脚本，受控网页模拟 X 的 article/tweetText/tweetPhoto/dialog 结构。验证流式完成、React 合并 span 后恢复且请求数保持一次；中文夹英文未进入请求/样本；“翻译选中”鼠标点击带覆盖层的图片成功读取 850×1200 原图并创建真实嵌字层；图片链接没有跳转；Esc 关闭译文；放大图片后自动本地判断一次。小图自动请求为零。浏览器脚本错误为零。

原位渲染和原图读取使用实际实现；模型响应为受控数据，未读取用户 API Key、未调用云端模型。真实 X 贴文在浏览器和网页读取工具中均返回 HTTP 403，所以本报告不将结构回归等同于真实账号页面验收。
