0.12.0 使用与补充验证

1. 退出旧程序后启动新版，并在 Chrome 重新加载本包扩展 0.7.0。
2. 确认服务商预设、API Key 和自动翻译开关恢复。
3. 打开长英文页面，检查多批次完成后不再提示笼统的“暂不可用”。
4. 其他标签翻译期间进入新页面，检查识别及时开始。
5. 中文及包含中文正文的双语页面保持原文；英文中仅有中文名字时可自动翻译。
6. 如果服务商配置错误，应显示具体原因。保存正确密钥后可重新开始。
7. 页面处于站点验证时等待验证，不翻译加载文字；正常正文出现后再判断。
8. 刷新或返回已翻译页面，已完成的译文继续使用缓存。

自动测试使用真实公开网页和受控本地流式响应；未读取个人 API Key。
Core14 语言模型已移除；图片检测与翻译功能保留。
