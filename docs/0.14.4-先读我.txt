全局 AI 翻译器 0.14.4 / Chrome 扩展 0.9.3

本版增加按 API 预设保存的网络连接：系统代理、直连、Clash 当前路由、Clash 指定节点、自定义 HTTP / HTTPS / SOCKS5 代理。

使用方法：翻译设置 → 选择预设 → API 网络连接 → 保存。
Clash 指定节点：先启动 Clash Verge 并使订阅生效，点击“读取 Clash 节点”，选择节点并保存。
没有安装 Clash Verge：设置页显示“前往 GitHub 下载”。该软件是可选项；系统代理、直连和自定义代理不依赖它。
官方地址：https://github.com/clash-verge-rev/clash-verge-rev/releases/latest

指定节点复用已安装的 Mihomo 内核，只读取当前节点配置，在后台建立独立通道。配置通过标准输入传递，不写入配置文件或命令行。不会切换 Clash 当前节点、重载主内核或修改订阅。不同预设可以同时使用不同节点。停止软件后独立通道退出。
直连仅关闭本软件的应用层代理，无法覆盖系统 TUN / VPN 路由。
自定义代理地址不支持内嵌账号密码；Clash 自带代理认证自动在本机读取，不写入预设。
指定节点从当前本地订阅缓存读取；节点被删除或缓存缺失时明确报错，不回退到其他线路。

所有翻译路径、模型列表、连接测试使用所选预设的网络设置。更换线路保留已有译文缓存。默认并发保持 10。

升级：退出旧程序，解压新包到新目录后运行 ScreenTranslator.exe。保留原有 API Key 和设置。浏览器扩展本版无改动；已使用 0.9.3 扩展无需重新加载。
