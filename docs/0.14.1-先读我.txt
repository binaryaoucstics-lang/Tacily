新增：自定义 API 读取模型列表
1. 在“翻译”设置中新增或选择服务商预设，填写 Base URL、API Key 并选择接口协议。
2. 点击模型框旁的“读取模型列表”。成功后自动展开列表供选择，也可以继续手填模型 ID。
3. 选择模型后保存。图片翻译请选支持图像输入的模型；读取列表本身不会调用翻译模型。
4. 支持 OpenAI 兼容 Chat Completions、OpenAI Responses 与 Anthropic Messages 模型列表；按当前协议使用相应鉴权。Claude 列表自动读取分页。
5. 本机 HTTP 服务支持无密钥查询。远程服务可用已保存密钥或尚未保存的新密钥读取。
6. 可取消；超时、无权限、不支持接口或空列表时给出提示，并保留已填写模型。
7. 切换预设、地址、协议或密钥时取消旧请求并丢弃迟到结果，不会串用其他服务商列表。
