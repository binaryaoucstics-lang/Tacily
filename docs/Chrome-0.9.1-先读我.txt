Chrome 扩展 0.9.1 更新包

适用于桌面程序 0.14.0。本次修复网页文字反复流式翻译、无法固定的问题。

更新方法：
1. 将本包 browser-extension 目录中的文件复制到正在使用的 browser-extension 目录，覆盖同名文件。
2. 打开 chrome://extensions/，找到“全局 AI 翻译器 · 网页与图片”，点击重新加载。
3. 确认扩展版本为 0.9.1，刷新已经打开的网页。
也可以在开发者模式下“加载已解压的扩展程序”，选择本包的 browser-extension 目录。
扩展标识与权限保持一致，已有桌面程序设置和密钥沿用。

修复内容：
- 逐字和逐词动画节点合并成句子或颜色/字重样式段；原有 DOM 结构、链接和样式保留。
- 零宽空白也参与句子提取，避免换行处丢空格；译文写入具有实际文字的节点。
- 动画内容短暂稳定后才送去翻译，避免逐字入场时反复翻译残句。
- 独立倒计时不再使同区域文字重新翻译；正文内有事实意义的时间仍参与上下文。
- 动态轮播变化只作废对应段落，其他段落继续输出和保存译文。

测试：313 项 JavaScript 测试通过。opengateway.ai 真实页面，1440×1000 和 390×844；使用受控流式响应，每批模拟 6.5 秒延迟，连续观察 24 秒。标题/简介只请求一次、无请求取消，译文在完成后保留；切换原文/译文、滚动与窄屏均保持稳定。页面无脚本异常或框架错误覆盖层。
测试未读取用户 API Key 或调用云端翻译模型；验证针对页面兼容性和流式显示，不评价模型翻译质量。
