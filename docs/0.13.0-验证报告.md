# 0.13.0 自动图片策略与点击选段

## 修改

- 图片自动翻译成为独立的两项策略，默认关闭；开启自动网页文字不再隐式开启图片。沿用原有保存的图片开关，无需新增设置字段或迁移用户密钥。
- 自动图片入队、预览读取、后台读取及正式翻译开始前均检查大小。显示短边至少 240 CSS 像素、长边至少 360、面积至少 120,000；视口占比至少 18%，或短边至少 400 且长边至少 600。实际可见面积至少 120,000，并在大视口下至少占 2%。以真实显示几何为准，原图分辨率不能使缩略图自动入队。
- ResizeObserver、图片/祖先的样式变化、点击、过渡结束与全屏变化触发复查，新增弹层图片通过增量扫描发现。小图不保留“已判断”状态，因此同源放大可入队；已完成判断保留，滚动或收起不会取消已接收任务。
- “翻译选中”按钮进入点击模式。用点击处附近实际文字行定位语义段落，收集该段的原始文本；输入区、代码、隐藏节点及扩展自身界面跳过。支持内联链接及开放的 Shadow DOM，距离超过 24 CSS 像素的空白不选取整容器。
- Esc 或再次点击按钮退出选择。段落里的链接在选择成功时拦截本次点击，原有链接和 DOM 保留，完成译文仍可缓存重放。
- 修复图片标识依赖仅安全上下文可用的 randomUUID 的问题；非 HTTPS 页面使用 getRandomValues 生成 UUID。

## 浏览器验证

独立匿名 Chrome for Testing；加载正式前端模块，执行真实鼠标和键盘动作。流式译文使用控制响应，图片使用程序生成的 PNG 并真实解码，不读取用户 API Key，不调用云翻译模型。

| 场景 | 结果 |
|---|---|
| Hugging Face Qwen-Image-2.1-Turbo 模型卡 | 点击定位 247 字符的段落，只发送该段，显示流式结果，无高亮选区 |
| 模型卡内联链接 | 点击定位整个段落，未跳转，href 和链接节点保留 |
| Hugging Face Spaces p=3 | 卡片描述点击定位成功，未发送同页其他段落 |
| 两页重复点击已译段落 | 新增翻译请求为 0；Esc 退出成功 |
| 自动图片默认关闭 | 大图与缩略图候选为 0，像素解码为 0 |
| 大图模式下的小图 | 候选为 0，像素解码为 0 |
| 同源缩略图从 160×220 放大 | 触发一次判断；收起并再次放大没有新增预览或候选 |
| 祖先 CSS transform 放大 | 未更改源图片，成功重新检查并触发候选 |
| 预览与关闭后的手动读取 | 两张预览各约 74,000 base64 字符，小图手动读取成功 |

点击到测试完成译文为 141 / 163 ms，其中测试流固定等待 100 ms；放大到测试预览完成为 29 ms。这些是受控响应的前端交互测量，不代表云模型耗时或 OCR 模型耗时。

## 回归和发布

核心测试 755 项、Windows 集成测试 615 项、扩展测试 293 项，共 1,663 项通过，无失败或跳过。

新增覆盖独立默认策略、大小与占比、放大前后的像素门禁、解码中收起、后台预览前检查、已接收任务滚出视口、整段点击范围、输入区保护、空白容器、内联链接、已译缓存及开放 Shadow DOM。

发布另执行真实 WPF 设置控件切换、本地 OCR 判断与定位、字体及原位嵌字运行检查；源码导出执行隐私扫描。没有新增第三方模型、依赖或浏览器权限，默认并发保持 10。
