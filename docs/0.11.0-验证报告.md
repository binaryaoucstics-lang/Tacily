# 0.11.0 服务商预设验证

## 变更

- 新增命名预设，可新增、复制、重命名、删除和切换。
- 独立保存协议、地址、模型、思考等级和加密密钥；默认服务商草稿保持独立。
- 协议支持 DeepSeek 官方、OpenAI 兼容 Chat Completions、OpenAI Responses 和 Anthropic Messages。
- 支持 HTTPS 兼容服务与本机 HTTP；端点自动补全且不重复追加方法路径。
- 原有三个服务商的密钥路径、配置和默认缓存标识保留。
- 自定义预设分别隔离缓存和密钥；重命名不会清除该预设的缓存。
- 通用 Chat Completions 不发送 DeepSeek 专有 thinking/reasoning_effort 参数；自定义未知模型使用服务端默认思考配置。

## 自动验证

核心测试 715 项，Windows 集成测试 601 项，Chrome 扩展测试 268 项；合计 1,584 项通过，无失败或跳过。

新测试覆盖三种自定义协议的端点、认证、模型和密钥路由；整图输入和 Chat Completions 流式输出；错误协议地址和带凭据 URL 拒绝；预设身份与缓存隔离；旧设置迁移；无密钥时不回退到其他服务商；预设参数切换、重启恢复、过期连接测试结果隔离；临时 Windows DPAPI 加密密钥与元数据持久化。

运行检查直接构建实际编译的 WPF 设置页，通过控件绑定编辑预设名称、模型和地址，确认预设可收集为运行配置。发布包还检查本地模型、字体、网页设置与三个原位嵌字区域。

接口验证使用合成 HTTP/SSE 响应，没有访问个人 API Key，没有发送网页或图片给第三方服务。自定义服务商的实际权限、视觉能力与兼容程度需填写 API Key 后用连接测试确认。
