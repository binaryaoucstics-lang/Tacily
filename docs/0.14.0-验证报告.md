# 0.14.0 验证报告

桌面版本 0.14.0，Chrome 扩展 0.9.0。

## 验证范围

- 网页圆点折叠、拖动阈值、边缘限制、窄屏布局、键盘点击及全屏视频隐藏恢复。
- 文本和图片阶段状态、折叠期间继续翻译、禁用动效及系统减少动画偏好。
- 小箭头二次展开菜单、保存忙碌状态、保存失败恢复、域名和继承规则说明。
- 快捷设置持久化、桌面控件绑定、跨标签页同步路由及当前域名校验。
- 白名单自动判断、黑名单阻止自动文本/图片、允许手动翻译、具体子域名优先和黑名单同级优先。
- 并发和网站规则变更时保留不受影响的手动流式请求。
- 新版发布目录的离线 OCR、嵌字、字体、设置控件、程序规则判断及默认配置检查。
