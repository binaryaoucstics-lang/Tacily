0.14.3 验收操作

升级桌面程序及 Chrome 扩展后刷新网页。
1. X 英语新闻及含时刻、章节或编号的日语贴文流式结束后应保留译文，切换原文/译文及滚动后不应撤回。
2. X 段落中文占有效文字一半及以上时不发往翻译服务；少量中文混入外语时仍正常翻译。纯日语假名加汉字应正常处理。
3. 开启自动图片“大图/点开放大”，打开 X 带英文文字的统计图，图片进入本地文字判断后自动翻译。小缩略图不自动提交。
4. 关闭自动图片翻译，使用“翻译选中”点击 X 图片，仍可读取整张原图并原位嵌字。点击普通段落仍无需手动高亮。
5. 没有文字的图片不应占用翻译任务；黑名单网站不自动翻译，手动入口仍可用。

请同时确认扩展版本为 0.9.3。只升级桌面程序而不重新加载扩展，图片识别修复不会生效。
