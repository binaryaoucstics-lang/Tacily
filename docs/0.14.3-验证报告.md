## 译文撤回

现场日志确认部分模型请求成功后被最终语义校验拒绝，前端恢复了原文。修复时刻的等价写法、日语暂停用语、中文序数及编号；保留更改数字、日期和明确上午/下午的拒绝检查。

航天新闻的真实流式过程再次复现后，发现 `Tianwen-3 Mars` 中的编号被误读为法语“3月3日”。新增编号边界约束及对应回归，并确认合法法语日期继续被校验。修复后该贴文的真实模型请求、最终提交、原文/译文切换及滚动检查均通过，最终记录 semantic_failed=0。

英语新闻贴文与日语贴文均显示完成译文；日语贴文滚动后原文未撤回。此检查仅覆盖所提供贴文的当次网页与模型响应，不能代表所有 X 贴文。

## 图片

X 真实 DOM 使用透明 img 加相邻背景 div 显示相同原图。现在仅在 X/twitter、同一精确图片 URL、可见背景层和支持的适配方式下，读取该背景层的几何；原始像素仍来自 img。测试覆盖 contain/cover、裁切、错误 URL、隐藏节点及其他域名。

实际打开所提供的统计图：1080×1350 原图，查看器采用 contain。自动本地文字判断约 426 ms，真实翻译请求完成约 3.6 s，生成 7 个嵌字块。关闭自动图片翻译后，使用“翻译选中”点击信息流中的图片，没有打开图片链接，完成了原图翻译并创建对应图片的嵌字层。测试后恢复了原有自动图片设置。

上述证明自动触发、原图读取及手动图片通路恢复；该统计图的嵌字位置和字号仍有改进空间，不作为美观度或完整文字覆盖率的达标证明。

## 中文比例

X 以段落及分行语境计算中文占 Unicode 有效字母的比例，达到 50% 才过滤；标点、数字、表情不计入分母。含假名的日语不会直接当中文过滤。加粗等节点边界不独立改变段落判断；正文中少量中文不会误触发整页中文否定。

## 验证环境与发布

Browser Use CLI 成功读取过当前 Chrome 的真实贴文结构。随后原窗口的 CDP 重连握手超时；完成检查使用 Browser Use 从既有 Chrome 配置复制的浏览器会话，访问真实 X 页面，接入正常用户环境中的翻译器和已配置翻译服务。未用模拟模型替代上述网页翻译，也未直接读取或输出 API Key。该范围与在原窗口复测有区别。

另执行新发布文件的离线运行检查；检查不读取 API Key，不联网、不捕屏或注入输入。包内二进制逐文件对应新发布目录。默认并发 10、缓存 256 MB；没有新增模型、依赖或浏览器权限。

截图、模型流式观察记录与含用户路径的连接诊断保留在私有工作目录，不进入公开源码或安装包。公开源码另执行隐私扫描；旧归档保留。
